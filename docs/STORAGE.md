# 数据与模型保留规则

GitHub 保存代码、配置、来源身份及必要的小型记录。数据、模型与大产物保存在服务器；`.gitignore` 排除这些文件，不通过 Git LFS 或压缩包变相上传。

## 保留

- 原始训练与官方数据、当前使用的共享 prepared512 缓存、固定 fit/dev 索引和年龄合同；同一份数据供多轮共用。
- 当前运行目录整体及其所有 checkpoint、索引、模型来源、日志、锁与退出证据。
- 后续候选仍需使用的公开预训练权重及原始来源、转换、provenance、license 链。
- 已完成实验中实际索引引用的 last、best、protected、native-initial checkpoint，唯一选定模型和已导出的提交模型。
- 官方一次评估 marker、冻结身份、原始预测和必要 sidecar、成功/失败/退出原件以及来源清单。
- 当前仍被 CPU 证据复用链引用的 fixture 原件；至少本轮最终交付核实前保留。

## 可清理

仅在盘点后列入具体删除清单：已确认无索引/冻结/来源/后继实验引用的 checkpoint、可再生且未在用的重复缓存、已验证有完整保留原件的重复大文件，以及不被使用的下载/解包临时件。失败现场和退出/指标原件不因清理而覆盖或删除。

删除前重新检查真实路径、类型、inode、大小、mtime 与占用；拒绝符号链接、活跃目录和新增/变化文件。保留删除清单、每项依据、真实退出码及释放空间回执。清理不获取训练锁、不发训练信号、不重新模型前向、不改变训练参数。

本轮清理结果将记入 `records/storage/`；盘点成功与实际删除分别报告。
