## 当前结构授权内的首选问题

**只保留一个有限候选：在同一公开 ImageNet R50 框架内，比较固定公开 BN 与仅从当前 fit 图像估计后固定的 BN。** 这是“统计适配”的匹配试验，不是 N06 复现，也不是新眼底预训练。

理由：N06 与普通 R50 都固定 BN，但被固定的统计分别来自视网膜预训练和 ImageNet；已有 N08/N13/R91 材料只证明固定公开统计，未见其中已做 fit-only 重估。这个问题可在不复制 N06 参数的条件下单独检验。未见先例不等于已穷尽全历史；更不证明统计失配就是本任务瓶颈。[AdaBN 原论文](https://arxiv.org/abs/1603.04779)仅提供一般方法依据，不提供本数据收益证据。

| 配对臂 | 共同起点与训练 | 唯一干预 |
| --- | --- | --- |
| 对照 | 独立公开 ImageNet1K V2 R50 fresh，标准 2048 维头和当前 fit-only age；同 seed、split、输入、损失、优化器与时钟 | 固定公开来源的 BN running statistics |
| 处理 | 与对照逐键相同的卷积、BN affine、新头、age 初值；同一训练合同 | 正式第 0 步前，仅用 fit 图像一次有界估计 BN running mean/var，此后固定 |

两臂共同 recipe 已定：公开 ImageNet1K V2 `resnet50-11ad3fa6.pth`，`resnet50_imagenet`、ImageNet 输入归一化、512 prepared/input、单视图、旧 training_scale 缺省 `[0.94,1.0]`、BCE（loss=None）、backbone LR 2e-5、head/age LR 1e-3、WD 1e-4、dropout 0.2、SD 0。不得一臂用 BCE、另一臂用 pairwise，或同时更换归一化/LR/增强。固定 9:1、当前 fit-only age、单模型、G64/P8、FP32、800 次成功更新一轮、最多 24000、内部 max(online,EMA) AUROC/min_delta0 连续 4 轮无提升早停，以及绝对 warmup/EMA 1600 均保留。job.seed 固定 20261029；现有 R50 factory 的 HEAD_SEED=20261027 保持，两臂逐键相同，不假称所有 RNG 都由 job.seed 控制。工程 train21600/total28800/GPUgrant32400 为上限，不是测得吞吐或实例租期承诺。

## 最低实现定义、成本和反例

- 校准只读 fit，不使用 dev/官方/test，亦不按标签或难例过采样；无 loss、梯度或 optimizer 更新。输入规范、统计估计式、batch/顺序、末批处理及各模块模式必须在实现前一次写清，不能边看 dev 边换校准算法。
- 校准时禁止 Dropout 等随机路径，并隔离 RNG 与数据加载消耗，使两臂正式训练的参数初值和后续主采样起点可核对。BN 使用 batch 统计会改变后层输入；一次遍历或滑动统计不等于精确总体矩，也不等于取得了 FLAIR 的表征。
- 公开完整 1000 类来源严格加载在校准前完成。处理臂只有 BN buffers 派生；其 derived BN digest、整体第 0 步状态与 EMA 身份必须实得，不能沿用公开 BN/full-state hash。保留 original provenance，记录派生来源，不修改历史 N06/N08 证明。
- 当前 `imagenet_resnet.py`、`ema.py` 已有固定 BN 运行/复制语义，可复用；但校准以及校准后初态绑定不是现成 JSON 开关。`experiment91.py`、正式 CPU candidate、初态和 checkpoint 检查含 ConvNeXt/768/noBN 假设，需按 R50/53BN/159 buffers 作必要分支。不能关闭校验后冒充适配成功，也不建设新的通用校准平台。
- 最大反例：真正差别可能主要在 FLAIR 学到的视觉特征，重估统计无法补足；fit 总体又被负例和采集风格主导，固定统计可能伤害少数正例。之后卷积继续训练，也可能使一次校准的统计不再合适。负结果只否定这一固定算法和合同，不能证明全部域适配无效。
- 多出一次 fit 前向及中等接口适配；不是免费操作，也没有实测速度保证。实际资产是否仍在 exp-v3、派生初态和耗时都由 A 后续正常执行时核实，不在此页称 ready。若适配必须扩为通用流程重构，放弃此候选，不再为它搭平台。

R112 校准 spec 固定为六字段：

```json
{"version":"fit-bn-fixed-reference-v1","estimator":"pooled_input_moments","reference":"public_bn_eval","accumulation_dtype":"float64","variance":"unbiased","output_dtype":"float32"}
```

1. 原 public full1000 strict 后构建同一 fresh 参数模型，保存原参数和 public BN 身份。`model.eval()`，在每个 BN 输入处安装 pre-hook；只运行 `model.backbone(images)`，不经过分类头/年龄分支。整次遍历中所有 BN 都使用原 public running mean/var，不进行 BN.train 或 SyncBN，无梯度和 optimizer 更新。
2. 只读当前 fit 的既有图像/cache，使用既有 evaluation 像素流程与 ImageNet 归一化；没有随机增强、标签筛选、重采样、补齐或 dev/official/test。按 fit 整数 index 升序、8 rank 分片 `[rank::8]`，每 rank batch32，保留最后不等长 batch。全局每张 fit 图只出现一次，实际 count 从清单取得。
3. 每层按除通道以外的全部维度收集 count/mean/M2，以 FP64 batch moments 和 Chan 公式合并。计数是每通道实际 `B*H*W` 元素数，使用 Python int/int64 或精确可表示的 FP64，不能用 int32。模型不包 DDP，局部前向可有不同 batch 数；结束后才在默认 WORLD all_gather 小统计，按 rank 顺序合并。无分布式初始化时仅作为单进程数学测试入口。
4. 全遍历结束后统一计算 `variance=M2/(count-1)`，finite/非负检查后 cast FP32 写入 106 个 mean/var buffer；53 个 `num_batches_tracked` 保持 public 原值，校准次数另记 receipt。所有参数、epsilon 均不改。保存/恢复逐模块 mode 与 Torch CPU/CUDA RNG，移除 hooks；正式训练加载其独立派生 BN identity 并固定全部 159 buffers，EMA 复制这些固定 buffers。
5. FP64 合并描述的是本次原 public-BN 网络的激活统计；统一替换后，前层输出会改变后层输入，因此它不是替换后全网络自洽统计。禁止因此增加逐层/迭代 pass。负结果只否定本算法和本合同。
6. 校准由 A 独占 GPU 串行执行，校准代码先 Git 冻结。R111 可在公共 R50 接线就绪后先启动；其安全退出后再做唯一校准与 R112。校准生成原件只在 exp-v3：106 浮点 BN 小资产及聚合 receipt，不复制 N06/FLAIR 或整套训练权重。派生整体初态不得沿用 public 初态，更不得沿用 Tiny/Small 控制。
