# A2：fit-only 模型显著图视盘定位的盲封可行性

2026-11-05 用户经 c607 授权新增 CPU 可行性检查；优先级低于 R270 和三折正式准备。此处只验证几何定位，不训练、不选分类模型、不读 dev 难例坐标或官方数据、不占 GPU、不改标签、不回灌训练。R120 在同一 fit 上训练过，显著图可能反映训练记忆，定位结果不能解释为独立泛化或临床证据。

## 事前固定方法

仅使用 F04 冻结的 R120 单成员，严格加载 [F04 冻结记录](../../records/analysis/20261104-f04/F04-FINAL-FREEZE.json)中其 fp16 导出 `model.pt` SHA `e0bc2c52dcc62adcb8ab4f4fe47c8126b31a0939732deca3985d5757c8d99e83` 及对应 metadata `86d4293ce357b8d109e008c4cd75f1d617937387cd435c3222f9ae52caa76861`；恢复为 CPU fp32、`eval()`，固定一次正类 logit 的 Grad-CAM。卷积特征固定为 `model.network.features[7]` 的输出；各通道权重为该 logit 对特征梯度在空间上的均值，逐通道加权和后 ReLU，双线性插值至 512×512，`align_corners=False`。使用生产的确定性居中 512 图像变换和 ImageNet 标准化，年龄输入固定 `[0,0]`，不使用标签或逐例年龄；不使用增强、TTA、其他模型或模型集成。

只在居中缩放后的图像矩形内计算显著图：有限值按该区域最小值/最大值做 min-max 归一化，差值 ≤`1e-12`、非有限值或有效正质量为 0 均记 unknown。取归一化图中 ≥`0.85` 的像素，以 8 连通分量分组，少于 16 像素的分量忽略；按最大值优先、并列时最上再最左确定主分量，主分量内按归一化值加权求质心。无主分量；或另一合格分量质心距主分量质心 >`0.15×512`；或以主分量质心为圆心、半径 `0.15×512` 内的显著图总质量不足全有效区域质量的 `0.30`，均记 unknown。定位成功时以该质心为中心生成 256×256 正方窗，按图像边界平移夹取；unknown 固定回退全图，评门时计失败。阈值、层、归一化、质心和回退一旦封存不得依据该批结果修改。

## 独立盲封与几何门

从原 46256 个 fit 索引中排除旧定位试验 96 个（名单 SHA `3602cf733c5542d7a5e5c8b0b469fb205212431456598d45ec9c8b82d59dbf90`）及上一双线索盲审 64 个（名单 SHA `2a24a2a40fe2f01454c6a45e150cedb5330c830d4fd47f069ceaae88eb088d19`），对余下升序索引使用 `random.Random(20261124).sample(..., 64)` 无放回抽取；名单身份和排除关系实际核验后封存。抽样不看标签、年龄、图像、模型分数或先前预测，缺项不替换。

先用真实只读 512 缓存或核 SHA 原图生成仅含匿名图像的盲审包，封存名单和包；执行者据无预测图包独立写 64 个视盘技术粗框或 unknown，封存全部粗框 SHA 后，才计算 Grad-CAM 及对照。粗框为非专家几何参照，不是专家分割或医学判断。按原 A 口径，至少 **63/64** 个固定窗须完整包含粗框且四边各留该框宽/高一半的余量；粗框 unknown、模型定位 unknown/回退及越界均计失败。另报完全包含、含余量、定位与人工 unknown、中心误差，并在同一封存的64例上使用原双线索固定规则计算同口径对照。未经门槛不得起草 A2 训练合同；未通过则关闭本固定方法并归档，不改阈值、不重抽样或利用该集补考。即使过门，原图坐标回映射仍需独立验证，训练模型和全部融合权重仍须符合总文件 ≤500,000,000 字节及非医学公开预训练规则。

最小实现范围为 `tools/diagnostics/fit_disc_attention.py` 和 `tests/test_fit_disc_attention.py`，复用现有盲包、几何对照及 F04 严格加载代码；必要时仅对这三个现有入口做有记录的窄改动。名单、图像、逐例粗框、显著图和预测仅留 exp-v3，Git 仅保存此合同、代码、聚合结果及小型真实回执。当前尚未抽样、封包、审阅或运行模型。
