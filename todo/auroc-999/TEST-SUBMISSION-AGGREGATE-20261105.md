## 统计口径（事前固定）

- **对齐**：四份文件的 `Image_name` 序列必须逐行完全相同、5855 行、无重复；不一致即中止并如实记录，不做按名字重排后的“尽力对齐”。
- **数值**：`Probability` 必须有限且落在 `[0,1]`；`Pred_Label` 只允许 `0/1`，并与 `Probability >= 0.5` 的判据对比一致率。
- **秩**：升序秩，并列取平均秩（Spearman 约定）。秩差定义为 `|rank_a - rank_b| / 5855`，报告 `> 0.10` 与 `> 0.20` 的样本比例（只给比例，不给名单）。
- **两两相关**：6 对，各给 Pearson 与 Spearman（Pearson 作用于概率，Spearman 作用于平均秩）。
- **分布**：每份给 `count/min/1%/5%/25%/50%/75%/95%/99%/max/mean/std`，及 `p >= 0.5` 的阳性率、`Pred_Label` 阳性率、两者一致率。
- **与 R120 内部 dev 的对照**：把 R120 测试集概率与 R120 内部 dev 概率分别视为两样本，给各自分位数、均值/标准差，以及经验 CDF 最大差（KS 统计量，只作描述）；并列出 dev 与测试集在 0.5 阈值处的阳性率差。
- **落差表**：`内部/官方 → 平台` 的 AUROC 与差值，四舍五入到 4 位；只列表，不做因果归因。
- 所有浮点输出保留 6 位有效数字以上的原始 float，不做二次舍入后再计算。
