# fit图片自身的视盘几何定位小试

当前R232的9600 EMA适配及原监督合同保持，下面只在准备池检验未来局部路线的必要条件，不提前判R232阴性。原36例审阅发现512存在细节损失，但未证明临床决定性；亮区裁剪、四角窗和旧组合阴性继续约束设计。不能用dev人工坐标训练，不能引入额外图像、医学预训练或临床标签。用户已要求仅凭现有图片/CSV自主推进，不再索取审阅者或其他材料。

唯一几何问题：仅依赖图片的亮圆对称性与主要血管密度，能否在未用于设置的fit小样本上可靠包含完整视盘及邻近区域。依据为[Giachetti等的原研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC4478982/)将两类线索结合的定位思路；原论文完整分割、专家精度及其外部数据结果不作为本项目证据。不使用作者模型或外部图像，下面是独立简化的几何实现和本地可靠性检验。

先按固定PCG-free Python Random(20261104)在原fit_indices上无放回均匀选96例并冻结名单，再shuffle同一随机流分为32例准备、64例保留验证。选择不看标签、年龄、预测或dev/官方；输出隐藏身份的真实512画布，先由当前AI技术审阅逐例封存可见视盘的粗框/中心及unknown，再显示算法位置。此几何框仅用于该fit侧可靠性分析，不称医学分割真值或修改疾病标签。所有unknown和画面外结构计入失败，不事后剔除。

固定实现从原RGB缩到最长边480的缩略图，用绿色通道暗线闭运算差分取得粗血管图；用去细线后的亮区域梯度向内投票，固定半径10/14/18/22/28/34/42像素，结合局部主要血管密度。输出定位及置信证据，常量图/无有效血管或对称投票返回unknown，不退回最亮点。这里只估计中心和局部窗口，不估杯盘比或疾病。准备32例可用于排查实现/坐标问题；保留64例解盲后不换阈值、半径、crop比例或重抽样补考。

事先可靠性门：64验证例至少63例的固定局部窗包含AI粗框和四边至少半个粗框宽/高的邻近余量；窗口边长固定原图短边的一半，边界平移夹取而不补虚构组织。另报中心误差相对粗框大小、unknown、低置信和原图出框个数；64例的图片级小样本结论不等于全部fit/dev/官方或临床精度。未过此门不将该定位器用于下一GPU实验，不因当前模型结果放宽门。

必要范围限于现有`runtime/bundle/retrain/preprocessing.py`的一个未接入默认路径的确定性定位函数、`tests/test_disc_localization.py`的独立几何oracle/翻转与常量图退让，以及`technical-prep/fit-disc-localization-20261104-4e0c`中复用`structure_review.prepare_packet`的私有抽样/展示/封存脚本。先缺行为RED，再CPU实现/必要GREEN；原默认预处理函数范围按精确源码复用。通过几何门之后，才固定一项模型假设和对应最小接入范围，不能把准备登记当作已能运行。

只用当前独占24核0–23、nice19/隐藏GPU，和当前训练96核24–119互斥；图片/名单/逐例坐标留exp-v3，Git只放源码、此合同及小型汇总。不得修改R232冻结、clock/token/grant或增加GPU预演/新Agent/资源。并行提前处理条件R233未启动绑定的足额窗口，避免当前长轮结束后才发现旧窗口不足。
