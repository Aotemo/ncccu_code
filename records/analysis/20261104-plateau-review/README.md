## 停滞原因（按证据强度）

1. **收益与已见seed差异处在相近量级。** 少量同配方换 seed 的差异为 0.0012–0.0026（R107/R108、R120/R121、R95/R101）；这些差异提示波动，尚不能估计可靠的噪声底。已有配对区间和同一dev的反复筛选也限制单次“严格胜出”的解释。
2. **新目标仍需明显减少剩余错序。** 用户已将raw AUROC目标直接改为0.995；R120剩余约8739等效错序对，达到0.995约允许4152对，需减少约一半。该估计来自同一固定dev的分母，不表示官方能达到同值；AP > 0.9仍是独立目标。
3. **错误集中且来源未定。** top20 正例承担约 75%–79% 错序；适配路线普遍“修复少于新增”（R238 相对 R107 修复 2258、新增 4994、净增 2736）。结构审阅中 36 例标签判读 uncertain，患者/双眼/近重复未排除。残余可能含标签噪声或图像不可分部分，未证实也未排除。
4. **存在泛化差距的迹象，但完整fit证据缺失。** 256图fit子集与完整dev的差距受子集大小和抽样影响，不能直接诊断完整fit欠拟合或过拟合；较大骨干与更长适配的已有阴性也不构成容量上限证明。此处原将R134R1 full-fit census记为未执行，经核[权威归档](../../R134R1/README.md)更正：它已唯一执行，约17秒后因LLVM输出超过全进程RLIMIT_FSIZE而工程失败、metrics=null；不能当作未执行、模型已加载或科学阴性，也不复用旧身份重试。
5. **用户已改变可尝试的组合范围。** 允许通用公开预训练和多模型融合、禁止医学/眼底预训练与TTA；融合成员/权重仅用内部dev选，官方只评最终冻结方案。N06等医学来源仍禁止用于当前方案；其历史官方成绩不作同条件比较或当前上限证据。
6. **流程使探索退化为平台区局部搜索。** 单因素 + 先胜双锚点才跑第二 seed，几乎每条路线止于单 seed 阴性；工程故障（R114、R130、R236、旧 R240）与回执开销进一步压缩有效 GPU 时间。
